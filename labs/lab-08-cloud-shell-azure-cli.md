## Objective

Use Azure Cloud Shell and the Azure CLI to manage resources directly from the command line, without relying on the Azure Portal UI.

## Core Concepts Covered

- Launching and using **Azure Cloud Shell** (Bash/PowerShell)
- Authenticating and setting the active subscription via `az account`
- Common **Azure CLI** commands for listing, creating, and managing resources (`az group`, `az resource`, `az vm`, etc.)
- Advantages of CLI-based, scriptable resource management over manual portal clicks
- Foundation for automation and Infrastructure-as-Code workflows

## Relevance

CLI fluency is essential for repeatable, auditable cloud operations — and for security work specifically, it enables scripted reconnaissance and configuration review (e.g., quickly enumerating resources, checking RBAC assignments, or pulling activity logs) far faster than navigating the portal manually.

## Skills Demonstrated

- Azure CLI usage via Cloud Shell
- Command-line resource management
- Groundwork for automation/IaC-style workflows
