## Objective

Provision access for a new employee using Microsoft Entra ID (formerly Azure AD) and apply Role-Based Access Control (RBAC) to scope their permissions appropriately.

## Core Concepts Covered

- Creating a new user account in **Microsoft Entra ID**
- Understanding Entra ID as the identity and access management backbone of Azure
- Assigning **RBAC roles** at the subscription, resource group, and resource scope
- The principle of **least privilege** — granting only the access required for a role
- Reviewing role assignments and access scope

## Relevance

Identity and access management is one of the highest-leverage areas in cloud security — misconfigured RBAC (overly broad roles, stale accounts, missing least-privilege enforcement) is a leading cause of cloud breaches. This lab builds direct, hands-on familiarity with the access model that underpins most cloud security audits and identity-focused assessments.

## Skills Demonstrated

- Microsoft Entra ID user provisioning
- RBAC role assignment and scoping
- Least-privilege access control principles
