## Objective

Deploy a simple HTTP-triggered endpoint using Azure Functions — Azure's serverless compute offering — without provisioning or managing a dedicated server.

## Core Concepts Covered

- Creating a Function App and associated storage/hosting resources
- Writing and deploying an **HTTP-triggered function**
- Understanding the serverless execution model: pay-per-execution, automatic scaling, no server management
- Testing the function endpoint and inspecting the returned response
- Reviewing function logs for execution details

## Relevance

Serverless endpoints are increasingly common as lightweight backends, webhooks, and automation triggers — including in security tooling (e.g., automated alert processing, lightweight API endpoints for internal tools). Understanding how a Function App is provisioned and exposed also builds intuition for identifying exposed or misconfigured serverless endpoints during a security review.

## Skills Demonstrated

- Azure Functions provisioning and deployment
- Serverless architecture fundamentals
- HTTP trigger configuration and endpoint testing
