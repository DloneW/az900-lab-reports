## Objective

Apply Azure Resource Manager (ARM) governance features — **tags** and **resource locks** — to organize resources and prevent accidental modification or deletion.

## Core Concepts Covered

- Applying key-value **tags** to resources and resource groups (for cost tracking, ownership, environment classification, etc.)
- Querying/filtering resources by tag across a subscription
- Creating **CanNotDelete** and **ReadOnly** resource locks
- Understanding lock inheritance across the resource hierarchy (subscription → resource group → resource)
- Scenarios where locks prevent unintended changes during deployments or maintenance windows

## Relevance

Tagging and locking are foundational to **cloud governance and security hygiene** — both directly applicable to security hygiene audit work, since poor resource organization and unlocked critical infrastructure are common findings in cloud security reviews.

## Skills Demonstrated

- Azure Resource Manager (ARM) governance: tagging strategy, resource locks
- Cloud resource organization and protection patterns
- Working within time-boxed sandbox/cloud-slice environments
